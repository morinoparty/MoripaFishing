`config.json`はプラグインのルートディレクトリ（`plugins/MoripaFishing/`）に配置されます。
起動時にファイルが存在しないか空の場合は、すべての項目を既定値で埋めたファイルが自動生成されます。
読み込み時に未知のキーは無視されるため、古い設定キーが残っていてもエラーにはなりません。

## Format

```json title="plugins/MoripaFishing/config.json"
{
    "world": {
        "defaultId": "default",
        "timeZone": "Asia/Tokyo",
        "refreshIntervalSeconds": 60,
        "defaultClimate": {
            "weather": {
                "type": "random",
                "weights": {
                    "SUNNY": 4,
                    "CLOUDY": 1,
                    "RAINY": 2,
                    "THUNDERSTORM": 1
                },
                "intervalHours": 8,
                "offsetHours": 0,
                "maxInclination": 30,
                "seed": "pepper"
            },
            "time": {
                "type": "real_time",
                "offsetHours": 0
            }
        }
    },
    "defaultLocale": "ja_JP"
}
```

## 各設定の説明

### world

ワールド関連の設定です。

- `defaultId`: デフォルトの釣りワールドIDを指定します（デフォルト: `default`）
- `timeZone`: 天候カレンダーと実時刻同期に使うタイムゾーンIDを指定します。`Asia/Tokyo`、`UTC`、`America/New_York`等のIANAタイムゾーンIDが使用可能です（デフォルト: `Asia/Tokyo`）
- `refreshIntervalSeconds`: 釣りワールドの状態を決め直して適用させる間隔を秒単位で指定します。1 以上（デフォルト: `60`）
- `defaultClimate`: ワールドごとの `climate` が `null` の場合に使う気候設定です。詳細は[気候](/docs/format/config/climate)を参照

`refreshIntervalSeconds`ごとに、Core はメインスレッドで各釣りワールドの天候・時刻などを決め直し、ロード済みのワールドへ Integration（[Weather](/docs/integration/weather) / [WorldLifecycle](/docs/integration/world-lifecycle)）を通じて適用させます。天候の変化（`FishingWorldWeatherChangeEvent`）もこの間隔で検知されます。`/mf reload` で値を変えると、新しい間隔でループを開始し直します。

ワールドボーダーの既定値は `config.json` ではなく、ワールドごとの設定（[ワールド設定](/docs/format/data/world)の `border`）で指定します。

:::warning[注意]
`timeZone`の値はそのままIANAタイムゾーンIDとして解決されるため、不正な文字列を指定すると天候や時刻の計算時に例外が発生します。
:::

### defaultLocale

プラグインのデフォルトロケールを指定します（デフォルト: `ja_JP`）。
i18nの翻訳ファイルと対応しており、プレイヤーへのメッセージ表示言語に影響します。
読み込み時は`_`を`-`に置き換えて言語タグとして解釈されるため、`ja_JP`と`ja-JP`のどちらの表記でも受け付けられます。自動生成されるファイルには`ja_JP`形式で書き出されます。

## 設定の再読み込みと書き戻し

`config.json`は`reload()`によって再読み込みされ、その時点のファイル内容が設定として反映されます。
またプラグイン内部から`applyConfig()`が呼ばれた場合は、保持している設定がそのまま`config.json`へ書き戻されます。
このためファイルを手動で編集した内容は、書き戻しのタイミングによっては上書きされる可能性があります。

## 関連するディレクトリ

`config.json`と同じルートディレクトリ配下には、用途ごとのサブディレクトリが用意されています。

- `rarity/`: レアリティの定義ファイル
- `fish/`: 魚の定義ファイル
- `world/`: 釣り場ワールドごとの詳細設定ファイル
- `translation/`: 翻訳メッセージのファイル
