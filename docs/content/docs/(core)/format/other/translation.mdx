MoripaFishingの表示文言は、Adventureの`MiniMessageTranslationStore`（キーは`moripafishing:translations`）に登録され、`GlobalTranslator`経由で解決されます。そのため翻訳値にはMiniMessage記法をそのまま書けます。

## 翻訳ファイル

翻訳ファイルは`plugins/MoripaFishing/translation/`に`<ロケール>.properties`という名前で配置します。ファイルはUTF-8で保存してください。

```bash
plugins/MoripaFishing/translation/
├── en_US.properties
├── ja_JP.properties
└── fr_FR.properties   # 任意のロケールを追加できる
```

- 初回起動時に、同梱の`ja_JP.properties`と`en_US.properties`がコピーされます。既にファイルがある場合は上書きしません。
- ディレクトリ内の`<ロケール>.properties`はすべて読み込まれます。ファイル名（`ja_JP`、`fr_FR`、`en`など）がそのままロケールになります。
- ファイル名は`言語`（小文字 2〜3 文字）または`言語_国`（国は大文字 2 文字）の形にしてください。`en_us.properties`や`messages.properties`のようにこの形に合わないファイルは、警告を出して読み込みません。
- 同梱されているロケールのファイルは、同梱の既定値の上に重ねて読み込まれます。ファイルに書いたキーだけが上書きされ、書いていないキーは同梱の既定値が使われるため、プラグインの更新で追加されたキーも表示されます。

なお`config.json`の`defaultLocale`（既定値は`ja_JP`）が翻訳ストアの既定ロケールになり、プレイヤーのロケールに対応する翻訳が無い場合のフォールバック先として使われます。

翻訳は`/mf reload`で再読み込みできます。このコマンドには`moripafishing.command.reload`権限が必要です。翻訳ファイルの読み込みに失敗した場合（不正な`\uXXXX`エスケープなど）は、以前の翻訳がそのまま使われます。

## 自動登録される翻訳キー

以下のキーは各JSON設定の`displayName`や`name`のロケールマップから登録されます。propertiesファイルに同じキーとロケールの翻訳がある場合は、propertiesファイルが優先されます。

| キー | 由来 |
| --- | --- |
| `moripa_fishing.fish.<fish_id>.name` | 魚設定の`displayName`。魚アイテムの表示名になります |
| `moripa_fishing.rarity.<rarity_id>.name` | レアリティ設定の`displayName` |
| `moripa_fishing.world.<world_id>.name` | ワールド設定の`name` |

## 魚

### Params

既定のlore（下記）と魚設定の`lore`では、以下のタグをプレースホルダとして利用できます。

<TranslateTable columns={[
    {
        name: "size",
        description: "魚のサイズ（常に小数点以下2桁）",
        example: "53.20",
    },
    {
        name: "rarity",
        description: "魚のレアリティ（翻訳済みの表示名）",
        example: "コモン",
    },
    {
        name: "angler",
        description: "つりびとの名前",
        example: "Chocolatt",
    },
    {
        name: "world",
        description: "ワールド名（翻訳済みの表示名）",
        example: "つりとぴあ",
    },
    {
        name: "timestamp",
        description: "釣り上げた日時（ZonedDateTimeをそのまま文字列化した値）",
        example: "2025-05-01T00:00+09:00[Asia/Tokyo]",
    },
]} />

`<rarity>`と`<world>`には、翻訳済みのComponentが直接埋め込まれます。`<size>`はサーバーのロケールに関係なく小数点に`.`を使います。`<timestamp>`は整形されないため、読みやすい日時にしたい場合はloreの書き方で工夫してください。

### デフォルト

すべての魚に共通して表示される3行です。値は`ja_JP.properties`と`en_US.properties`で定義します。

`moripa_fishing.fish.lore.default.rarity` : レアリティについて

`moripa_fishing.fish.lore.default.size` : サイズについて

`moripa_fishing.fish.lore.default.angler` : つりびとについて

初期状態の`ja_JP.properties`は次のようになっています。

```properties title="ja_JP.properties"
moripa_fishing.fish.lore.default.rarity=<white><gray>レアリティ: </gray><rarity>
moripa_fishing.fish.lore.default.size=<white><gray>サイズ: </gray><size> cm
moripa_fishing.fish.lore.default.angler=<white><gray>釣った人: </gray><angler>
```

なおloreは常にイタリック装飾が解除された状態で表示されます。

#### 魚ごとの説明文

魚設定の`lore`は翻訳キーとしては登録されず、アイテムを作る時点でMiniMessageとして解釈されます。既定の3行の後に、プレイヤーのロケールの`lore`（無ければ`defaultLocale`の`lore`）が続けて表示されます。上のプレースホルダーはここでも使えます。詳しくは[さかな](/docs/format/data/fish)を参照してください。
