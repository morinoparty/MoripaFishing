サーバー管理者向けの MoripaFishing 導入・設定ガイドです。

## 動作要件

| 項目 | 要件 |
|------|------|
| Minecraft | Paper 26.3 以降（開発とテストは Paper 26.3 で行っています） |
| サーバー | Paper または Paper 互換サーバー（Purpur など） |
| Java | 25 以降 |
| 任意プラグイン | [WorldLifecycle 統合](/integration/world-lifecycle)（釣りワールドの作成に必須）、[Weather 統合](/integration/weather)、[Terra](https://modrinth.com/plugin/terra)（`terra` ジェネレーターを使う場合）。統合プラグインは MoripaFishing 本体に必須依存するため、本体と一緒に導入してください |

:::warning[注意]
MoripaFishing は Paper プラグイン (`paper-plugin.yml`) として配布しています。Spigot サーバーには対応していません。
:::

## インストール

### mpm でインストールする

[mpm](https://mpm.plugin.morino.party) を導入済みのサーバーでは、次のコマンドでインストールできます。手動で配置する場合は下の手順に進んでください。

```bash
# 本体 + 統合プラグイン（WorldLifecycle / Weather）
/mpm add MoripaFishing --soft

# 本体のみ
/mpm add MoripaFishing

# 統合プラグイン・アドオンを個別に追加
/mpm add MoripaFishing-Integration-WorldLifecycle
/mpm add MoripaFishing-Integration-Weather
/mpm add MoripaFishing-Addon-CatchAnnounce
/mpm add MoripaFishing-Addon-Chum

# 更新
/mpm update
```

### 1. JAR ファイルの取得

以下のいずれかから最新の JAR ファイルをダウンロードしてください。

- [Modrinth](https://modrinth.com/plugin/moripafishing)
- [GitHub Releases](https://github.com/morinoparty/MoripaFishing/releases)

JAR ファイルは `<プラグイン名>_<バージョン>.jar` という名前で、Core は `MoripaFishing_<バージョン>.jar` です。Integration と Addon も同じリリースに含まれており、ファイル名はそれぞれのプラグイン名から始まります（例: `MoripaFishing-Integration-WorldLifecycle_<バージョン>.jar`）。

### 2. プラグインの配置

ダウンロードした JAR ファイルをサーバーの `plugins/` ディレクトリに配置します。

```bash
plugins/
├── MoripaFishing_<バージョン>.jar
└── MoripaFishing-Integration-WorldLifecycle_<バージョン>.jar
```

:::note
釣りワールドを作成するには WorldLifecycle 統合プラグインが必要です。詳しくは [WorldLifecycle](/integration/world-lifecycle) を参照してください。
:::

### 3. サーバーの起動

サーバーを起動すると、`plugins/MoripaFishing/` ディレクトリに設定ファイルが自動生成されます。

```bash
plugins/MoripaFishing/
├── config.json          # メイン設定
├── translation/         # 翻訳ファイル (<ロケール>.properties)
│   ├── en_US.properties
│   └── ja_JP.properties
├── fish/                # 魚データ
├── world/               # ワールドデータ
└── rarity/              # レアリティデータ
```

なお、ジェネレーターの定義ファイルは Core ではなく WorldLifecycle 統合プラグイン側が管理しており、`plugins/MoripaFishing-Integration-WorldLifecycle/generator/` に配置されます。初回起動時に `terra` / `void` / `normal` の 3 つが既定として書き出されます。

起動時には `world/` 配下の JSON が読み込まれ、釣りワールドとして定義されます。全プラグインの読み込みが終わった後（サーバーの起動完了時）に、対応する Bukkit ワールドがまだロードされていないものは WorldLifecycle 統合で作成されます。WorldLifecycle 統合が未導入だったり、指定されたジェネレーターが見つからなかったりした場合は、警告ログを出してそのワールドを未ロードのままにします。

## 初期設定

### config.json の基本設定

`plugins/MoripaFishing/config.json` を編集して基本設定を行います。
詳細は[コンフィグ](/format/config)を参照してください。

主な設定項目:

- **デフォルトワールド**: `world.defaultId` でデフォルトの釣り場IDを指定します
- **タイムゾーン**: `world.timeZone` でタイムゾーンを設定します（デフォルト: `Asia/Tokyo`）
- **言語**: `defaultLocale` で翻訳が見つからない場合に使う言語を設定します（例: `ja_JP`）

### 釣りワールドの作成

プラグイン導入後、釣り用のワールドを作成します。

:::warning[注意]
ワールドの作成には [WorldLifecycle 統合プラグイン](/integration/world-lifecycle) が必要です。未導入の場合、ジェネレーターの候補が表示されず、作成は `Failed to create world <id>.` で失敗します。
:::

```
/mf world create <ワールドID> <generator>
```

`<generator>` には WorldLifecycle 統合が読み込んでいるジェネレーターの ID を指定します。既定では `terra` / `void` / `normal` の 3 つが利用できます（`terra` を使う場合は別途 Terra プラグインが必要です）。

例:
```
/mf world create fishing_world normal
```

釣りワールドは `moripafishing:<ワールドID>` というキーの Bukkit ワールドとして作成されます。そのためワールド ID には、英小文字・数字・`_`・`-`・`.`・`/` だけを使用できます。

ワールド作成後、以下のコマンドでスポーン地点やワールドボーダーを設定できます。

| コマンド | 説明 |
|----------|------|
| `/mf world list` | 釣りワールドの一覧とロード状態を表示 |
| `/mf world transfer <world> <player>` | プレイヤーを指定した釣りワールドへ移動（ロード済みのワールドのみ） |
| `/mf world config set spawn <world>` | スポーン地点を現在位置に設定 |
| `/mf world config set center <world> [x] [z]` | ワールドボーダーの中心座標を設定（省略時は実行したプレイヤーの現在位置） |
| `/mf world config set size <world> <size>` | ワールドボーダーのサイズを設定 |
| `/mf world config unset border <world>` | ワールドボーダーを管理対象から外す |
| `/mf world config view <world>` | ワールドの設定と現在の天候を確認 |
| `/mf world delete <world>` | 釣りワールドの登録を削除 |

:::note
`/mf world delete` はプラグインからの登録解除のみを行い、サーバー上のワールドフォルダは削除しません。不要になったデータは手動で削除してください。
:::

### 魚・レアリティの設定

`plugins/MoripaFishing/fish/` と `plugins/MoripaFishing/rarity/` に JSON ファイルを配置して、釣れる魚とレアリティを定義します。

- 魚データのフォーマット: [魚データ](/format/data/fish)
- レアリティのフォーマット: [レアリティ](/format/data/rarity)
- ジェネレーターのフォーマット: [ジェネレーター](/format/data/generator)

## 権限設定

コマンドの権限は通常の Bukkit のパーミッションノードとして定義されているため、LuckPerms などの権限プラグインでそのまま設定できます。

| パーミッション | 説明 |
|----------------|------|
| `moripafishing.command.reload` | `/mf reload` |
| `moripafishing.command.world.list` | ワールド一覧の表示 |
| `moripafishing.command.world.transfer` | プレイヤーの移動 |
| `moripafishing.command.world.create` | ワールドの作成 |
| `moripafishing.command.world.delete` | ワールドの削除 |
| `moripafishing.command.world.config` | ワールド設定の変更・表示 |

## 設定の反映

設定ファイルを変更した後は、以下のコマンドで再読み込みできます。

```
/mf reload
```

このコマンドはメイン設定、各釣りワールドの設定と状態、レアリティ、魚、翻訳ファイルの順に再読み込みします。詳しくは [管理コマンド](/commands/admin) を参照してください。
