釣り上げた魚の情報を表すデータクラスです（`party.morino.moripafishing.api.model.fish.CaughtFish`）。実装依存を持たない純粋なデータ構造で、`AnglerFishCaughtEvent`と`AnglerFishCaughtResultEvent`でのデータ受け渡しと、釣果アイテムに使用されます。

`@Serializable`が付与されているため、kotlinx.serializationでそのままJSON化できます。釣果履歴やランキングのように、Addon側で永続化やAPI返却を行いたい場合はこのクラスをそのまま利用できます。Core自体は釣果を保存しません。

## フィールド

| フィールド | 型 | 説明 |
|---|---|---|
| `uniqueId` | `UUID` | 釣果の一意ID（ランダムな UUIDv4） |
| `fish` | `FishId` | 魚種ID |
| `rarity` | `RarityId` | レアリティID |
| `size` | `Double` | 魚のサイズ。表示時は小数2桁に整形される |
| `lengthRate` | `Double` | サイズの累積分布関数値（0〜1）。価値の計算式の `length_rate` と同じ値 |
| `worth` | `Double` | 魚の価値 |
| `angler` | `AnglerId` | つりびとID。プレイヤーの Minecraft UUID と同じで、JSONでは UUID 文字列になる |
| `world` | `FishingWorldId` | 釣り場ワールドID |
| `timestamp` | `ZonedDateTime` | 釣った日時。ISO8601形式の文字列としてシリアライズされる |

`FishId`・`RarityId`・`FishingWorldId`はいずれも`value: String`を持つデータクラスで、専用のシリアライザによって文字列として直接シリアライズされます。生の識別子を取り出したい場合は`caughtFish.fish.value`のように`value`を参照してください。

`fish`・`rarity`・`world`の各IDは、それぞれ`moripa_fishing.fish.<id>.name`、`moripa_fishing.rarity.<id>.name`、`moripa_fishing.world.<id>.name`という翻訳キーに対応しています。閲覧者のロケールに応じて表示名を出し分けたい場合は、各IDの`toTranslatable()`が返すコンポーネントを使ってください。翻訳キーが登録されていない場合は、キーの代わりにIDが表示されます。翻訳キーそのものが必要な場合は`toTranslateKey()`で取得できます。

```kotlin
val message =
    Component.text()
        .append(caughtFish.fish.toTranslatable())
        .append(Component.text(" ("))
        .append(caughtFish.rarity.toTranslatable())
        .append(Component.text(")"))
        .build()
```

## 保存した釣果を扱うときの注意

釣果履歴やランキングのように`CaughtFish`を保存しておく場合、後から参照したときには、その魚・レアリティ・ワールドの定義がすでに削除されていることがあります。期間限定の魚の定義を削除した場合などが該当します。

- `FishManager.get(caughtFish.fish)`や`RarityManager.get(caughtFish.rarity)`は`null`を返すことがあるため、必ず`null`を扱ってください。
- 削除された定義の表示名は翻訳から外れます（翻訳ファイルで同じキーを定義している場合は、その翻訳が引き続き使われます）。`toTranslatable()`を使っていれば、この場合もIDが表示されます。`Component.translatable(id.toTranslateKey())`を直接使うと、翻訳キーがそのまま表示されたり、何も表示されなかったりします。

```kotlin
// 定義が削除されている場合は null になる
val rarityWeight = api.getRarityManager().get(caughtFish.rarity)?.weight
```

定義の削除が Core と釣果アイテムに与える影響は[期間限定の魚を終了する](/format/data/fish#期間限定の魚を終了する)を参照してください。

## 生成

`CaughtFish.of(fish, angler, world)`で、抽選済みの`Fish`（`FishDrawer`の戻り値）と`AnglerId`・`FishingWorldId`から生成できます。`uniqueId`はランダムなUUID、`timestamp`は生成時点の`ZonedDateTime.now()`が自動的に設定されます。

```kotlin
val drawer = api.getFishDrawer()
val fish = drawer.draw(drawer.createPool(worldId)) ?: return
val caughtFish = CaughtFish.of(fish, angler.getId(), worldId)
```

## 釣果アイテム

Coreが生成する釣果アイテムのPersistentDataContainerには、キー`moripafishing:caught_fish`に`CaughtFish`のJSONが文字列として保存されます。アイテムから釣果を復元できます。

```kotlin
val key = NamespacedKey("moripafishing", "caught_fish")
val json = item.persistentDataContainer.get(key, PersistentDataType.STRING) ?: return
val caughtFish = Json.decodeFromString(CaughtFish.serializer(), json)
```

## 利用例

釣果は、`AnglerFishDrawEvent`（抽選の直前・重みの変更が可能。[抽選確率の変更](/addons/draw-weights)）の後に抽選した魚から作られます。
`AnglerFishCaughtEvent`（釣り上げ確定前・キャンセルや差し替えが可能）と、
`AnglerFishCaughtResultEvent`（釣り上げ完了後・読み取り専用）から釣果データを取得できます。
通知や記録などの副作用には`AnglerFishCaughtResultEvent`を使用してください。

```kotlin
@EventHandler
fun onFishCaught(event: AnglerFishCaughtResultEvent) {
    val angler = event.getAngler()
    val caught = event.getCaughtFish()
    logger.info("つりびと: ${angler.getName()}, 魚: ${caught.fish.value}, サイズ: ${caught.size}, 価値: ${caught.worth}")
}
```

一方、`AnglerFishCaughtEvent`は`Cancellable`を実装しています。`setCancelled(true)`でキャンセルすると、Core側のリスナーが元の`PlayerFishEvent`もキャンセルするため、釣果アイテムは生成されず釣り自体が成立しません。特定条件で釣りを禁止したい場合に利用できます。

```kotlin
@EventHandler
fun onFishCaught(event: AnglerFishCaughtEvent) {
    if (isFishingBanned(event.getAngler())) {
        event.isCancelled = true
    }
}
```

また`AnglerFishCaughtEvent`では`setCaughtFish(caughtFish)`によって釣果そのものを差し替えられます。差し替えた内容はアイテム化と後続の`AnglerFishCaughtResultEvent`の両方に反映されます。ただし未登録の`FishId`へ差し替えるとアイテムを生成できず、その場合はバニラのドロップが維持され、`AnglerFishCaughtResultEvent`は発火しません。
別の魚種に差し替える場合は、`copy(fish = ...)`ではレアリティ・サイズ・価値が元の魚のまま残るため、`FishDrawer#roll`で差し替え先の魚を抽選し直してから`CaughtFish.of`で釣果を作り直してください（[API利用ガイド](/addons/api-guide#anglerfishcaughtevent)）。
